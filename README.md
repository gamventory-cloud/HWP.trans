# 설문지 변환기 (한글 → 워드)

한글(`.hwp` / `.hwpx`)로 만든 설문지를 워드(`.docx`) 설문지로 옮깁니다.
표로 짜 놓은 리커트 척도 문항을 표 그대로 살리는 것이 이 도구의 목적입니다.

```
설문지.hwp ──> 문단·표 추출 ──> 중간 텍스트(사람이 수정) ──> 설문지.docx
```

중간 텍스트를 한 단계 끼워 넣은 이유: 한글 설문지는 서식이 제각각이라 자동 인식이
항상 맞지 않습니다. 텍스트 한 판을 눈으로 훑어 고치는 편이 완성된 docx를 손보는
것보다 빠릅니다.

## 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

명령줄에서도 쓸 수 있습니다.

```bash
python -m hwp_survey.cli 설문지.hwp 결과.docx --dsl 중간.txt   # 변환 + 중간 텍스트 저장
python -m hwp_survey.cli 중간.txt 결과.docx --from-dsl         # 고친 중간 텍스트로 다시 굽기
```

## 중간 텍스트 문법

| 표기 | 뜻 |
|---|---|
| `# 제목` | 설문 제목 |
| `> 안내문` | 인사말·연구 목적 |
| `~ 상자글` | 테두리 상자 (용어 정의, 유의사항) |
| `## Ⅰ. 섹션` | 섹션 제목 |
| `! 지시문` | 문항 아래 작은 안내 |
| `1. 문항 [단일]` | 문항 + 유형 태그 |
| `- 보기` | 보기 (표 유형이면 표의 행) |
| `-- 소제목` | 표 안 소제목 행 (예: '자율성'에 관한 문항입니다) |

유형 태그: `[단일]` `[복수]` `[단답]` `[장문]` `[척도:1-7]`
`[표:① 전혀 그렇지 않다,②,③,④,⑤ 매우 그렇다]`

## 구조

```
app.py                  Streamlit 화면
hwp_survey/reader.py    .hwp / .hwpx -> 문단·표 추출
hwp_survey/parser.py    추출 결과 <-> 중간 텍스트 <-> 렌더링 블록
hwp_survey/writer.py    블록 -> .docx
hwp_survey/cli.py       명령줄 진입점
```

## 형식별 지원 범위

| 형식 | 방법 | 비고 |
|---|---|---|
| `.hwpx` | ZIP + OWPML(XML) 직접 파싱 | 가장 정확. 한글에서 *다른 이름으로 저장 → HWPX* 권장 |
| `.hwp` (5.x) | `pyhwp`의 XHTML 변환 후 파싱 | 표 구조 보존 |
| `.hwp` (3.x 이하), 암호 문서 | 미지원 | 한글에서 다시 저장한 뒤 사용 |

`hwp5txt`(순수 텍스트)를 쓰지 않는 이유: 표가 `<표>` 한 줄로 사라져 리커트 문항이
통째로 날아갑니다. 그래서 XHTML 변환 경로를 씁니다.

## 알아둘 점

* **줄바꿈 채움 공백** — 한글에서 줄 끝을 공백으로 채워 정렬한 흔적 때문에
  `만족  ` + ` 감을` 같은 조각이 생깁니다. 기본값은 이것을 붙여
  `만족감을`으로 되살리지만, 단어 사이를 여러 칸 띄운 곳은 반대로 붙어버릴 수
  있습니다. 사이드바에서 끌 수 있고, 중간 텍스트에서 고치면 됩니다.
* **글꼴** — 문서에 글꼴 이름만 심습니다. 워드로 여는 컴퓨터에 해당 글꼴이 없으면
  다른 글꼴로 대체되어 보입니다.
* 자동 인식은 원본 서식에 좌우됩니다. 문항 수가 실제와 다르면 중간 텍스트를
  확인하세요.
